# Vault

Generated markdown. Do not edit by hand — the pipeline overwrites it.

- `interviews/` — one structured note per transcript, with YAML frontmatter so any
  model or tool (Obsidian, grep, Claude) can read it.
- `synthesis/latest.md` — the current cross-interview synthesis and recommendation.
- `synthesis/synthesis-YYYY-MM-DD.md` — dated snapshots, so you can show how the
  conclusion changed as interviews came in.
