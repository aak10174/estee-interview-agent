System architecture

Reading twelve interviews the same way twice

A pipeline that turns consumer interview transcripts into a structured markdown vault, finds what several people said independently, and answers questions about it over Telegram — so the argument put in front of Estée Lauder traces back to a named participant and a verbatim quote, every time.

Language Python 3.9+ Model Claude, 2 call types State plain markdown, in git Runs on cron or GitHub Actions

The flow

Every arrow is a file being written or read. There is no database and no hidden state — if a claim is in the synthesis, the note it came from is sitting in the repo next to it.

What each file is responsible for

Seven modules, one job each. The model is reached through exactly one of them.

ModuleJobTalks to Claude
claude.pyThe only place the API is called. Swapping the key or the model is a one-line change here.—
analyze.pyOne transcript → one structured note. Hashes the source file, so re-runs skip work already done.1 × per interview
synthesize.pyEvery note → intersections, tensions, outliers, and a recommendation with its counter-evidence.1 × per run
vault.pyLoads the notes and answers a plain-language question against them, with aliases cited.1 × per question
bot.pyTelegram long-polling loop. Remembers its offset, so restarts don't replay old messages.—
telegram.pyRaw HTTP to the Telegram API. Splits messages at the 4096-character limit.—
pipeline.pyAnalyse → synthesise → digest. What the scheduler actually runs.1 × for the digest

What one note holds

Each interview is extracted into the same shape, and every field carries the verbatim quote it was drawn from. The three fields in violet are the ones the synthesis reads to decide which strategic question the research can actually answer — the interviews decide, not us.

participant summary brand perception unmet needs discovery channels purchase drivers purchase barriers price sensitivity product preferences competitors chosen instead notable quotes tensions signal · attracting Gen Z signal · channel investment signal · portfolio direction

A field nobody discussed comes back as not discussed rather than a plausible guess. That is the difference between a vault you can defend in a room and one that reads well until someone asks where a number came from.

Two places it can run on a schedule

Same pipeline, same code. What changes is whether the laptop has to be awake, and whether the vault comes back into the repo on its own.

Where the secrets live

This repo is meant to be handed to someone else and made public. That constraint shaped the layout.

Ships in the repo

  • .env.example — the shape of the config, no values
  • src/ — all seven modules
  • vault/ — notes and synthesis, meant to be read
  • interviews/ — transcripts, once you decide they can be public

Never leaves the machine

  • .env — API key, bot token, chat id. Gitignored.
  • .state/ — poll offset and run logs. Gitignored.
  • On GitHub Actions the same three values come from repo secrets, which are write-only once set.

Consent is the open question, not the code: transcripts are identifiable even under an alias if the interview is specific enough. Decide whether interviews/ goes public before the first push, because git remembers.

Handing it over

Three commands, in this order — the account you are authenticated as when you create the repo is the account that owns it.

  1. Authenticate as him.

    gh auth login — his GitHub account, on your laptop.

  2. Create and push.

    gh repo create estee-agent --public --source=. --push — the repo is created under his account, with your commits intact.

  3. Switch back.

    gh auth switch — then he clones, runs make setup, and puts his own key and bot token into .env. Nothing else changes; your key never left your laptop.

One caveat worth keeping next to the output: this system reports patterns in what people said. Interviews over-represent whoever agreed to be interviewed, and people are unreliable narrators of their own spending. The synthesis is a sharpened set of hypotheses for Estée Lauder to test — not a measurement of the market.
